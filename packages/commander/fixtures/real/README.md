# Real Commander captures

Put captures from the Van Buren Commander here. `*.xml` in this folder is git-ignored by default, because journals hold store data. Commit a file only after checking it: card data removed (run it through the agent's redactor), no passwords or cookies.

Wanted for Phase 2, all for the **same closed day**:

- `periodlist.xml` (`vtlogpdlist`)
- `reportperiodlist.xml` (`vreportpdlist`)
- `transset-daily-<filename>.xml` (`vtransset`, period 2)
- `transset-shift-<filename>.xml` (`vtransset`, period 1)
- `ruby-summary-<filename>.xml`, `ruby-tax-<filename>.xml`, `ruby-department-<filename>.xml`, `ruby-network-<filename>.xml`
- A photo or scan of that day's printed day-close report, for the reconciliation test
